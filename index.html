GET /nsm/v1/devices Stable
Returns a paginated list of all firewall devices registered to the authenticated tenant. Supports filtering by status, model family, and firmware version.
Query Parameters
ParameterTypeRequiredDescription
tenant_idstringOptionalFilter to a specific tenant. Omit to return devices across all tenants in the API key scope.
statusenumOptionalFilter by: online, offline, degraded. Defaults to all statuses.
limitintegerOptionalResults per page. Min: 1, Max: 200. Default: 50.
page_tokenstringOptionalCursor from previous response. Use next_page_token from prior call.
